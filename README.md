# Wian1977

I build small Linux desktop tools. The one I spend most time on right now is **miniam** — Apple Music in your terminal, with true-color album art, a live spectrum and keyboard controls in one window. Space pauses, `n` skips. Prebuilt Linux x86_64 binaries are available, no Rust toolchain needed.

我在做一些 Linux 桌面上的小工具。目前花时间最多的是 **miniam** —— 在终端里听 Apple Music：真彩封面、动态频谱和键盘控制都在同一个窗口，空格暂停，`n` 切歌。提供 Linux x86_64 预编译二进制，不需要 Rust 工具链。
